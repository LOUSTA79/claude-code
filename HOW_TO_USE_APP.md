1. **Open the app** in your browser
2. **Tap the ⚙️ button** (top right)

## 🐛 Troubleshooting

### "Please set your OpenAI API key"
- Tap ⚙️ button
- Paste your API key
- Tap Save

### "API Error"
- Check your internet connection
- Make sure you copied the full API key
- Verify your key at platform.openai.com

### "Quota exceeded"
- You've used your free $5 credits
- Add payment method on OpenAI platform
- Or wait for monthly reset

### App won't open
- Make sure you're opening in a modern browser (Chrome, Samsung Internet)
- Try downloading the file instead of viewing in GitHub
